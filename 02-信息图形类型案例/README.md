## 归档原则
- 一个类型一个文件夹，包含至少一份与 PPT 案例关联的 Markdown 说明；需要更多案例时添加新的 Markdown，而不是把图片放入数据逻辑文件夹。
- 课件第3–21页的五种数据组织逻辑另保留在 [01-信息图形数据逻辑](../01-信息图形数据逻辑/)；不与常用表现类型混为一类。
- 案例图片按用户后续提供的具体案例逐张补入对应类型文件夹；图片文件与 Markdown 分析文档保持同目录，并在文档中使用相对路径引用。
- 课件只给中文的类型，英文标注为“归档译名”，不视为 PPT 原文。
- 后续每增加案例时，检查数据逻辑、统计方法、视觉编码、信息架构、视觉叙事、出处与版权。
