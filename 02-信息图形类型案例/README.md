## 归档原则
- 一个类型一个文件夹，包含至少一份与 PPT 案例关联的 Markdown 说明；需要更多案例时添加新的 Markdown，而不是把图片放入数据逻辑文件夹。
- 课件第3–21页的五种数据组织逻辑另保留在 [01-信息图形数据逻辑](../01-信息图形数据逻辑/)；不与常用表现类型混为一类。
- 案例图片按用户后续提供的具体案例逐张补入对应类型文件夹；图片文件与 Markdown 分析文档保持同目录，并在文档中使用相对路径引用。
- 课件只给中文的类型，英文标注为“归档译名”，不视为 PPT 原文。
- 后续每增加案例时，检查数据逻辑、统计方法、视觉编码、信息架构、视觉叙事、出处与版权。

- **抽象空间网络与多层数据关系图**：见[地理图形信息图形说明文档](17-地理图形信息图形/地理图形信息图形说明.md)。主要数据逻辑为空间定位、节点分布与路径连接，辅助使用网络关系图、气泡/散点、放射结构和条形标记；图片已归档。
- **自然地形与河流空间结构信息图**：见[地理图形信息图形说明文档](17-地理图形信息图形/地理图形信息图形说明.md)中的“案例02”。主要数据逻辑为地形高程、路径连续性与自然要素空间分布，辅助使用等高线、地形层叠表达、空间分布和统计表格；图片已归档。
- **Visualizing the Biomass of Life（生命的生物量可视化）**：见[三维信息图形型说明文档](16-三维信息图形型/三维信息图形型说明.md)中的“案例03”。主要表现类型为三维信息图形型，底层数据逻辑为编目型并进行类别间定量比较；以单位方块、分层立体结构、类别标签和动物插画表达不同动物类别的生物量。
