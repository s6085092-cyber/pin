# 案例 01：El mundo del Estéreo Picnic

## 图片内容概述
该信息图以哥伦比亚 Estéreo Picnic 音乐节为主题，展示 2010—2018 年九届音乐节的演进信息。画面将年份沿弧形/放射式路径组织，并在各年份附近配置艺术家或乐队标志、音乐类型、数量标注及规模信息。左侧另列参演乐队的国家来源数量，底部补充 2018 年场次、艺术家数量、国际/本地艺术家及投资金额等信息。

## 分类判断
- **主要表现类型**：时间轴型信息图形（Timeline Infographics）。
- **主要数据逻辑**：编年型。
- **辅助表现方式**：放射状条形图、圆形/气泡式数值标记、分类列表、Logo 符号。
- **辅助数据逻辑**：编目型（音乐类型、国家、艺术家等分类字段）。
- **判断依据**：2010—2018 年份构成连续的时间主线，各届音乐节信息依附于相应年份展开。与纯编目型不同，年份不是普通属性标签，而是版面组织和阅读推进的主要骨架。

## A. 基本的数据逻辑
编年型信息图形的本质，是数据对象具有明确的时间属性，并以时间先后关系作为主要组织规则。通常可抽象为：
**时间点/时间段 → 对应事件或阶段 → 该时间下的属性与指标 → 跨时间比较**。

本案例的数据结构包括：
1. **时间维度**：2010—2018 年九届音乐节；
2. **事件/对象维度**：每届音乐节及其参演艺术家、乐队；
3. **分类维度**：音乐类型、参演国家等；
4. **数量维度**：不同届次或分类下的数量，以及底部 2018 年汇总指标。

其中时间维度控制主阅读路径，音乐类型、国家与艺术家属于附着在时间节点上的分类和描述信息。因而主逻辑是编年型，编目型是辅助逻辑。

## B. 使用的统计图形与计算方式
本案例将时间轴与多种统计图形结合，不是单一统计图表。

1. **放射状条形图/尖峰条形表达**：蓝色放射状条形按类别排列，条形长度和旁侧数字承担数量比较功能。可对应分类计数或分组汇总；应以原始数据确认每个条形的指标口径。
2. **放射式/弧形时间轴**：年份沿弧形路径排列，承担时间排序与阶段定位功能。年份位置用于表示顺序，不应自动理解为精确的时间间隔比例。
3. **圆形/气泡式数值标记**：不同大小的浅紫色圆形配合 2,600、4,500、6,000、25,000、45,000、50,000、60,000、65,000、75,000 等数字，形成规模提示。仅凭画面无法完全确认圆面积是否按数值平方根或线性比例映射，分析时不应擅自断言其精确计算公式。
4. **分类列表与计数**：左侧国家名称及对应数量，属于分类汇总和排序列表。
5. **底部指标汇总**：呈现 2018 年相关场次、艺术家数量、国际/本地艺术家及投资额等摘要信息。

## C. 视觉编码
- **点**：年份节点、艺术家/乐队 Logo、圆形数值标记，用于识别时间、对象和规模提示。
- **线**：弧形路径和细连接线将年份、音乐类型、艺术家与数据关联起来；线条承担阅读引导和对应关系。
- **面**：蓝色放射状条形是主要定量编码区域，长度用于比较数量；浅紫色圆形形成数值标记的视觉底面。
- **体/面积**：圆形大小强化规模感，但具体面积映射规则需原始数据或图例验证。
- **符号**：艺术家 Logo 和音乐相关图标替代部分文字标签，增加主题识别度。
- **色彩**：蓝色用于突出统计条形；浅紫色用于背景数值节点；黑色用于文字与 Logo；整体以有限色彩维持复杂版面的统一。
- **文字**：年份沿路径旋转排列，类别文字顺应放射方向；大标题建立主题层级，底部图标指标提供摘要信息。
- **空间布局**：弧形/放射式结构将多个年份和多组分类信息纳入同一画面，同时通过外围留白与局部注释缓解信息密度。

## D. 数据/信息架构
本案例采用“主题介绍 → 时间主线 → 年度条目 → 分类与数量细节 → 汇总指标”的结构。

- **主题层**：Estéreo Picnic 音乐节发展概况。
- **时间层**：2010—2018 年九个年度节点。
- **年度内容层**：每届对应的艺术家/乐队及音乐类型。
- **统计细节层**：放射状数量条形、国家来源列表及规模标注。
- **总结层**：2018 年演出与艺术家相关指标、投资金额等。

后续分析同类案例时，应记录每个统计值对应的年份、类别、单位和统计口径，避免把不同口径的数字直接比较。

## E. 视觉叙事架构
叙事从音乐节主题和简介开始，沿弧形时间路径由 2010 年逐步推进至 2018 年。读者在每个年份节点看到相应的艺术家标志和音乐类型，再通过条形长度、数字标注和国家列表理解各届音乐节的内容规模与构成。最后，底部汇总信息将阅读从历届细节收束到 2018 年的总体情况。

可概括为：
**主题引入 → 2010 年起点 → 年份逐届推进 → 音乐类型/艺术家/国家数据展开 → 2018 年汇总收束。**

## 与相近类型的辨析
| 易混淆类型 | 本案例的关系 | 判断依据 |
|---|---|---|
| 编目型 | 辅助逻辑 | 音乐类型、国家和艺术家属于分类条目，但不是主阅读顺序 |
| 混合型信息图形 | 辅助表现特征 | 融合多种统计图形和符号编码，但时间主线仍然统摄整体 |
| 单一图表型 | 不属于 | 同时使用时间轴、放射状条形、分类列表及汇总指标 |
| 地标型 | 不属于 | 没有以地理位置或路线作为主要组织结构 |

## 方法辨析与更新建议
时间轴型是表现类型，编年型是其常见底层数据逻辑。判断时应确认时间是否真正控制主阅读顺序，而不能仅凭画面出现年份就归类为时间轴。若一个案例同时出现分类列表、条形图和气泡图，应记录为复合视觉表达，但仍按主导信息组织逻辑确定主分类。

对于本案例，后续若获得原始数据，应核实：各年份条形所代表的统计对象、圆形大小的数值映射、国家数量的统计口径，以及底部 2018 年汇总数据的来源。

# 案例 02：BAUHAUS（包豪斯历史与发展环形时间轴）

## 图片内容概述
该信息图以“BAUHAUS”为主题，围绕沃尔特·格罗皮乌斯（Walter Gropius）及包豪斯相关历史展开。画面中央放置格罗皮乌斯人物肖像，背景叠加世界地图；外围以红色环形曲线组织年份与历史节点，并在时间轴外侧配置建筑照片、年份标题和简短说明。顶部还安排人物合影及人物/学校介绍，使主题背景、人物线索和建筑案例共同构成历史叙述。

画面中可辨认出多个年份标签，例如1883、1910、1920、1925、1926、1928、1936、1937、1958、1959、1963等；环形路径附近还出现其他年份标记。由于部分小字和年份说明在当前图片分辨率下无法完全辨读，本案例仅依据清晰可见的时间标签、人物肖像、地图和建筑图片进行结构分析，不补写无法确认的事件细节。

## 分类判断
- **主要表现类型**：时间轴型信息图形（Timeline Infographics）。
- **主要数据逻辑**：编年型（Chronological）。
- **辅助表现方式**：环形时间轴、历史里程碑、建筑图片注释、人物肖像、世界地图背景。
- **辅助数据逻辑**：编目型（建筑/人物/地点等对象的分类与说明）。
- **判断依据**：年份和历史事件构成主要阅读线索，建筑图片依附于相应时间节点展开。中央人物与世界地图用于建立人物和地理背景，但没有取代时间顺序成为主组织结构。
- **类型边界**：虽然画面包含地图、人物照片和建筑图片，但它们主要承担背景说明与事件佐证功能；因此不优先归为地理图形型、图片式或混合统计图表型。

## A. 基本的数据逻辑（Data Logic）

### 1. 数据结构本质
本案例的核心数据结构是“时间节点—历史事件—关联对象”。每一个节点以年份为索引，附带事件说明、建筑/项目图片，必要时关联人物或地点。

可抽象为：

`T_i = (Year_i, Event_i, Person_i, Place_i, Building_i, Description_i)`

其中年份是主排序字段，事件是主要内容，人物、地点、建筑照片和说明文字是附属字段。

### 2. 数据逻辑特点
- **单向时间顺序**：年份构成由早期至后期的阅读推进线索。
- **节点式记录**：历史不是连续数值曲线，而是由若干离散事件组成。
- **多对象关联**：人物经历、学校发展、建筑实践与地理位置通过时间节点联系起来。
- **阶段性**：不同年份和事件可形成早期经历、学校发展及后续影响等阶段，但具体阶段边界应以可靠史料为依据。
- **编目辅助**：建筑名称、人物和国家/地区属于可分类的对象信息，但它们附着于时间节点，不是全图的主排序规则。

因此，本案例的底层数据逻辑是编年型，而不是单纯的人物目录或建筑作品目录。

## B. 使用了怎样的统计图形（Statistical Graphics）

本案例主要使用时间组织图形与历史图像注释，并非以统计计算为核心的定量图表。

1. **环形时间轴（Circular Timeline）**：红色弧线构成主要时间路径，年份沿曲线分布，形成环绕中心人物的阅读结构。
2. **里程碑节点（Milestone Markers）**：时间轴上的节点标记关键年份，并通过连接线与外围事件模块关联。
3. **图片注释图（Annotated Image Timeline）**：建筑照片与文字说明作为历史事件的视觉证据，补充年份节点的内容。
4. **地理背景图（Context Map）**：中央浅灰色世界地图提供地理语境，辅助理解人物和包豪斯相关活动的地域联系；它不是用于精确呈现地理统计值的主图。
5. **人物肖像与合影**：用于人物识别和历史背景说明，不承担数量统计功能。

### 可扩展的统计方法
如果后续取得经过核实的完整事件资料，可以增加：
- 各时期建筑/项目数量统计；
- 不同国家或城市的项目数量比较；
- 人物活动时间跨度；
- 不同阶段的事件密度。

这些属于可扩展的分析方向，原图没有明确提供完整数据集或统计口径，不能将其视为原图已经计算的结果。

## C. 视觉编码（Visual Encoding）

- **点**：时间轴上的小型节点标记年份或历史事件；地图上的圆点用于提示地理位置；人物肖像圆框强化人物识别。
- **线**：红色弧线是主时间路径；细红色虚线/引导线连接年份节点与建筑照片；灰色细线辅助地图和背景信息的组织。
- **面**：浅米白背景构成整体画布；浅灰世界地图作为低对比度背景面；外围建筑图片和文字块形成独立信息模块。
- **体**：建筑摄影本身呈现建筑的体量、立面和空间形态；中央人物肖像形成视觉重量。这里的“体”主要来自真实照片，而不是将数值转换成三维统计体量。
- **符号**：人物肖像代表历史人物；建筑照片代表建筑项目或历史事件；年份数字代表时间节点；地图及地点标记提供地理参照。
- **色彩**：红色用于主时间轴、年份和重点标记，形成强烈的时间导航；黑色用于标题和正文；灰色用于地图与辅助信息；米白色作为背景，营造历史档案感并保持整体克制。
- **字体与字号**：BAUHAUS标题使用大字号粗体，建立主题识别；年份以醒目的红色大字突出；说明文字缩小作为补充信息。
- **空间布局**：中央人物构成视觉中心，环形时间轴围绕人物展开，建筑图片分布在外围。中心—环绕式布局将人物、时间与建筑案例统一在一个视觉系统中。

## D. 数据/信息架构（Information Architecture）

整体采用“主题识别—人物中心—时间主线—事件图文模块—地理背景”的组织方式。

1. **主题层**：顶部BAUHAUS标题和简介，明确研究对象。
2. **人物层**：中央格罗皮乌斯肖像，以及顶部人物合影/介绍，建立核心人物线索。
3. **时间层**：红色环形时间轴及年份标签，承担主要阅读导航。
4. **事件层**：外围建筑图片、年份标题和说明文字，解释各时间节点对应的历史内容。
5. **背景层**：世界地图和地点标记，提供地理语境。

每个事件模块可抽象为：年份 → 事件标题 → 建筑/人物图像 → 简要说明。读者可以先沿环形路径识别时间顺序，再转向外围查看对应事件的图片和文字。

## E. 视觉叙事架构（Visual Narrative）

本案例采用“主题建立—人物聚焦—时间环绕—建筑事件展开—历史关系回看”的叙事方式。

1. **主题建立**：通过BAUHAUS大标题及顶部介绍，明确包豪斯主题。
2. **人物聚焦**：中央人物肖像将格罗皮乌斯设为叙事入口，让观众先建立人物认知。
3. **时间推进**：红色环形时间轴引导观众沿年份阅读历史节点。
4. **事件展开**：外围建筑照片与文字说明把抽象年份转化为可识别的建筑和历史内容。
5. **关系回看**：世界地图、人物照片和建筑分布共同补充人物活动与包豪斯发展的背景关系。

可概括为：

**主题引入 → 核心人物 → 环形时间推进 → 建筑/事件图文展开 → 人物、地点与历史关系整合。**

## 与相近类型的辨析

| 易混淆类型 | 本案例的关系 | 判断依据 |
|---|---|---|
| 编年型信息图形 | 主要数据逻辑 | 年份和历史事件决定主阅读顺序 |
| 编目型信息图形 | 辅助逻辑 | 建筑、人物、地点可被分类，但不是主轴 |
| 地理图形信息图形 | 辅助背景 | 地图提供地理语境，没有承担主要空间数据分析 |
| 混合型信息图形 | 有复合视觉元素，但非首要归类 | 多种图像和符号共同服务于同一条时间叙事，而不是多个独立统计图表的组合 |
| 图片式信息图形 | 辅助表现 | 建筑照片是事件佐证，年份时间轴仍是组织骨架 |

## 设计方法与可借鉴之处
- 将人物肖像放在中心，以人物作为复杂历史信息的视觉锚点。
- 使用环形时间轴突破传统横向/纵向时间轴的版式限制。
- 将建筑照片放在时间轴外围，形成“时间节点—历史实物”的对应关系。
- 使用单一强调色突出时间路径和年份，避免多色造成主线分散。
- 地图只承担背景定位作用时，应降低对比度，避免与主时间轴争夺注意力。
- 年份较密集时，应控制标签方向、间距和连接线交叉，保证阅读顺序清晰。
