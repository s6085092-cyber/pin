## 案例 01：人体关节健康信息图

### 图片内容概述
画面以中央大型人体正面插画为视觉主体，在肩、肘、腕、髋、膝、踝等关节位置设置深色定位区域，并通过引线连接周围的局部关节放大图和结构说明。左侧包含关节介绍、分类表、运动动作研究、曲线图及分步骤训练动作；右侧以多组局部解剖示意和动作图解释不同关节；顶部和底部穿插条形图、比例图、分类统计及健康提示。

### 分类判断
- **主要表现类型**：解剖结构型信息图形（Anatomical Infographics）。
- **辅助表现类型**：混合型信息图形（Mixed Charts）、示意图型（How-to Infographics）、文字型/列表型。
- **底层数据逻辑**：以层级型和编目型为主。
- **判断依据**：整张图的主视觉和空间组织均围绕人体整体及局部关节结构展开。年份并不控制阅读顺序，因此不是编年型；统计图表虽多，但服务于关节健康主题，不构成主导组织逻辑。

### A. 基本的数据逻辑（Data Logic）
本案例的核心是**整体—部位—结构—功能/问题—干预方法**的关联组织，而非时间序列。

1. **整体与局部**：人体整体作为总览，肩、肘、腕、髋、膝、踝等作为局部节点。
2. **分类关系**：不同关节按身体部位、结构特点或功能进行分类。
3. **关联关系**：将关节结构与运动方式、活动能力、常见问题及训练建议联系起来。
4. **比较关系**：通过比例图、条形图和曲线图呈现不同类别或指标之间的差异。

从数据结构看，层级型体现为“人体整体→关节部位→局部结构”；编目型体现为“关节类别→结构/功能/动作条目”。两种逻辑共同支撑主体解剖叙事。

### B. 使用了怎样的统计图形（Statistical Graphics）
本案例不是单一统计图，而是统计图表与解释性示意图的组合。

1. **横向条形图**：用于比较不同组别或指标的数值大小。通常通过条长编码数量，适合类别间比较。
2. **饼图/环形图**：用于表达整体中的构成比例。若数据总和为整体，可按“类别数值÷总数×100%”计算占比。
3. **曲线图**：用于表现某个连续变量或活动范围的变化关系；横纵轴的确切指标应以原图图注或原始数据为准。
4. **结构定位图与局部放大图**：中央人体插画标出关节位置，圆形或局部框放大具体结构；这属于解释性图解，不是统计图。
5. **动作步骤图**：通过连续姿势展示动作方法和训练过程，承担操作说明功能。
6. **分类表与图标清单**：将关节、动作或相关信息按类别组织，帮助检索和对照。

**计算边界**：原图中部分文字和数值分辨率有限，无法可靠辨认所有指标名称、样本口径及计算公式。因此这里只判断图表类型和一般统计方式，不推断具体数值含义，也不将示意图面积视为精确数据编码。

### C. 视觉编码（Visual Encoding）
| 视觉元素 | 本案例中的使用方式 | 信息作用 |
|---|---|---|
| 点 | 关节定位点、局部标记、图表数据点 | 标识人体位置或数据位置 |
| 线 | 引导线、连接线、曲线和图表坐标线 | 建立局部结构与主体之间的对应关系 |
| 面 | 人体色块、图表区域、分栏底色 | 区分主体、重点和信息模块 |
| 体/空间 | 中央人体整体插画、关节局部放大图 | 呈现整体与局部的空间关系 |
| 符号 | 关节图标、动作姿势、人体小图 | 将复杂知识转化为易识别的视觉符号 |
| 色彩 | 橙红、黑色、米白及少量灰色 | 橙红突出重点结构，黑色强化轮廓和文字，米白提供阅读背景 |
| 文字 | 标题、注释、编号、数据标签 | 建立层级并补充图形无法独立表达的信息 |

**视觉优化方法：**
- 以中央人体作为视觉锚点，降低多模块并列造成的迷失感。
- 通过关节定位色块和引线，把人体位置与周边局部说明一一对应。
- 用局部放大图突出复杂结构，形成“整体定位—局部解释”的阅读关系。
- 统一橙红、黑、米白的主色体系，让结构重点、说明文字和背景保持区分。
- 以编号、标题和分栏控制信息密度，避免所有文字和图表争夺同等注意力。

### D. 数据/信息架构（Information Architecture）
整体采用**中心主体式 + 周边模块式**架构。

| 版面区域 | 信息内容 | 作用 |
|---|---|---|
| 顶部 | 比例指标、横向统计图及小型图标 | 提供主题背景和概览数据 |
| 左侧 | 关节介绍、分类表、动作研究、曲线图、训练步骤 | 解释基础知识与运动方法 |
| 中央 | 完整人体插画及关节定位 | 建立全图核心参照 |
| 右侧 | 多个关节局部放大图、结构说明和动作示意 | 深入解释具体部位 |
| 底部 | 分类统计、训练内容和健康提示 | 汇总信息并引向实践 |

信息层级可归纳为：
**主题概览 → 人体整体 → 关节部位 → 局部结构/功能 → 统计辅助 → 运动与保护建议。**

### E. 视觉叙事架构（Visual Narrative）
本案例采用从整体到局部、从认知到应用的叙事方式：

1. **建立主题认知**：顶部数据和介绍引出关节健康主题。
2. **认识人体整体**：中央人体插画帮助读者建立关节位置的整体概念。
3. **逐个理解局部**：沿引线查看肩、肘、腕、髋、膝、踝等关节的局部结构。
4. **联系运动与问题**：结合动作示意、曲线及统计图，理解关节活动和相关知识。
5. **转化为实践**：通过训练动作和保护建议，引导读者将信息用于日常运动与关节保护。

可概括为：
**整体认知 → 部位定位 → 局部拆解 → 功能/运动解释 → 训练与保护。**

## 与相近类型的辨析
| 类型 | 本案例中的关系 | 判断依据 |
|---|---|---|
| 解剖结构型 | 主要类型 | 人体及关节结构决定全图主体和空间组织 |
| 混合型 | 辅助表现 | 同时使用条形图、比例图、曲线图、解剖图和图标 |
| 示意图型 | 辅助表现 | 使用动作分解和局部结构说明 |
| 层级型 | 底层逻辑之一 | 人体整体到具体关节存在上下级关系 |
| 编目型 | 底层逻辑之一 | 关节部位、功能和动作以类别条目组织 |
| 编年型 | 不属于 | 年份不构成主阅读顺序 |

## 方法辨析与更新建议
解剖结构型是以对象内部结构、部件位置及相互关系为主线的表现类型，既可用于人体/生物，也可用于机械设备等对象。判断时不能只看画面是否出现人体，而要看“结构关系”是否决定主要阅读路径。

本案例虽然包含较多统计图表，但统计图是辅助证据；人体整体和局部关节的定位关系才是主叙事。因此应归入解剖结构型，而不是仅因图表数量多就归入混合型。

后续补充同类案例时，建议记录：主体对象、整体与局部的层级、局部定位方式、是否有剖面/放大、统计图表类型、图例与单位、数据来源，以及图解与统计数据之间的对应关系。
