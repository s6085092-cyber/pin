# 三维信息图形型（3D Infographics）

## 案例03：Visualizing the Biomass of Life（生命的生物量可视化）

### 归档判断
- **主要表现类型：三维信息图形型（3D Infographics）**。
- **底层数据逻辑：编目型（Catalog）**，同时包含分类项目之间的定量比较。
- **辅助表达方式：比例单位图（Unit Chart / Isotype-like unit encoding）与分类注释**。
- **分类说明**：本案例的识别重点是将不同动物类别的生物量转译为分层、展开的三维方块体量，因此在“信息图形表现类型”中归入三维信息图形型。编目型描述的是其数据组织逻辑，而不是最终的主要表现类型。它并非编年型：没有时间序列；也不宜归为混合统计图表：画面主体不是多种常规统计图的拼接。

### 案例内容与画面观察
作品以“Visualizing the Biomass of Life”为题，聚焦动物界不同生物类别的生物量，并以碳质量（Gt C）作为计量口径。画面中央将立体方块组合成一组由上至下分层展开的体量结构；各层对应不同动物类别，左右两侧配置类别名称、数值标签、简短介绍及代表性动物插画。右上角另设单位说明：一个小方块代表100万吨碳，1000个小方块代表1吉吨碳（1 Gt C）。

图中可辨识的类别及标注值包括：
- 海洋节肢动物（Arthropods Marine）：1.0 Gt C
- 鱼类（Fish）：0.7 Gt C
- 环节动物（Annelids）：0.2 Gt C
- 陆生节肢动物（Arthropods Terrestrial）：0.2 Gt C
- 软体动物（Mollusks）：0.2 Gt C
- 刺胞动物（Cnidarians）：0.1 Gt C
- 家畜（Livestock）：0.1 Gt C
- 线虫（Nematodes）：0.02 Gt C
- 人类（Humans）：0.06 Gt C
- 野生哺乳动物（Wild Mammals）：0.007 Gt C
- 野生鸟类（Wild Birds）：0.002 Gt C

以上为画面中可读的类别与标签值；本说明不据此推算未标注的总量，也不将示意性立体透视视为精确测量坐标。

## A. 基本的数据逻辑（Data Logic）

### 1. 数据结构本质
本案例以“共同主题下的并列分类条目”为基础：每个条目代表一种动物类别，每个类别对应一个生物量数值及说明字段。其核心结构可表示为：

`动物类别（Category） → 生物量碳质量（Value） + 类别说明（Description） + 代表物种（Examples）`

不同类别共享同一计量单位，因而能够进行横向数量比较。条目之间主要是并列关系，而非时间先后、因果链或严格的上下位层级。

### 2. 数据逻辑判断
- **编目逻辑**：把动物界拆分为若干可识别的类别条目，并为每项配置统一字段。
- **比较逻辑**：以Gt C为共同单位，比较不同类别所对应的生物量规模。
- **单位图形逻辑**：将数值映射为可计数的小方块，使抽象数量转化为视觉单位。
- **三维表现逻辑**：把分类数据组织为有厚度、层面和空间分隔的立体模块。

因此，本案例的底层数据逻辑是编目型，三维体量是主要视觉转译方式。

## B. 使用了怎样的统计图形与计算方式（Statistical Graphics）

### 1. 主要图形形式
- **三维比例方块图 / 立体单位图（3D Proportional Unit Blocks）**：以重复的小方块构成各类别的立体模块，表达不同生物量的规模。
- **分层展开结构（Exploded / Layered 3D Structure）**：将类别模块沿垂直方向分层排列，使类别之间既保持整体关联，又能逐项辨识。
- **分类数值标签**：在模块两侧直接标注类别名称与Gt C数值。
- **具象类别插画**：用动物形象提示类别含义，补充纯数值难以传达的生物对象信息。

### 2. 计量单位与映射
画面给出的单位说明为：
- 1个小方块 = 100万吨碳（1 million metric tons of carbon）。
- 1000个小方块 = 1吉吨碳（1 Gigaton of Carbon，1 Gt C）。

由此可将类别数值转换为单位方块数量。若类别生物量为 (B_i) Gt C，则理论单位数为：

`N_i = B_i × 1000`

例如，1.0 Gt C对应1000个单位方块；0.7 Gt C对应700个单位方块。图中方块的立体排列主要服务于数量感知与视觉比较，阅读精确值时仍应以数值标签和单位说明为准。

### 3. 可使用的统计计算
若获得完整、同口径的原始数据，可进一步计算：
- 类别占比：`P_i = B_i / B_total × 100%`
- 类别差值：`D_ij = B_i - B_j`
- 类别倍数：`R_ij = B_i / B_j`

这些是可用于扩展分析的计算方式；画面本身没有明确展示所有类别占总体的百分比，也没有提供完整原始数据表，因此不应把这些派生指标当作原图已呈现的数据。

## C. 视觉编码（Visual Encoding）

### 1. 点与基本单位
重复的小立方体是最小视觉计量单元。单元重复形成数量感，也建立了“一个方块对应固定碳质量”的阅读规则。

### 2. 线
方块表面的网格边线用于分隔单位、强调排列秩序；细引导线将类别名称、数值标签与对应立体模块连接起来，减少标签归属歧义。

### 3. 面
每一层方块组合形成独立的平面或台层。层与层之间留出间距，帮助观众辨认不同类别，同时保留整体堆叠结构。

### 4. 体
通过轴测视角、顶面与侧面的明暗差异、模块厚度及层间留白，构成立体体量。三维深度强化了数量的物质感，但也可能造成透视误差，因此精确比较应优先参考标注数值和单位图例。

### 5. 符号与图像
螃蟹、鱼类、蠕虫、软体动物、家畜、人类、鸟类等小型插画作为类别索引；类别英文名称、数值标签和简短描述共同承担解释功能。插画是语义符号，不应被误读为额外的数据点。

### 6. 色彩
- 主体采用橙红、朱红与砖红色，建立统一的视觉主题并突出方块结构。
- 方块正面、侧面和阴影使用不同明度，辅助识别立体方向。
- 浅米白背景降低视觉噪声，保证文字和主体对比。
- 数值标签使用较醒目的暖色底块，便于快速定位。

### 7. 版式与字体
标题位于顶部，中央立体结构占据主要视觉区域，左右两侧交替布置标签和说明。衬线标题与较细的说明文字形成层次，数值标签承担快速扫描入口。

## D. 数据/信息架构（Information Architecture）

整体采用“主题说明—单位图例—中央分类体量—两侧条目注释”的结构。

1. **主题层**：顶部标题“Visualizing the Biomass of Life”与简短导语，说明作品关注生命世界的生物量。
2. **计量解释层**：右上角说明生物量的含义、碳质量口径和单位方块换算规则。
3. **主体分类层**：中央立体模块按类别分层展开，构成全图主要信息载体。
4. **条目注释层**：左右两侧分别标注类别名称、Gt C数值、类别简介和代表性物种。
5. **辅助识别层**：动物插画帮助读者把抽象分类与具体生物对象对应起来。

每个条目的字段相对统一：类别名称 → 数值及单位 → 类别解释 → 代表性物种示例。统一字段让读者可以在不同类别之间反复切换比较。

## E. 视觉叙事架构（Visual Narrative）

本案例采用“提出总体问题—解释计量规则—逐类展开—形成数量认知”的非时间型叙事。

1. **提出主题**：标题提出生命世界生物量这一总体议题。
2. **建立尺度**：通过右上角立方体图例解释一个单位方块代表的碳质量，建立读图基准。
3. **展开分类**：观众沿中央由上至下的立体层次阅读不同动物类别。
4. **逐项解释**：左右两侧的类别标签、数值和代表物种说明，为每个立体模块补充语义。
5. **完成比较**：不同层的体量和数值形成直观对照，使读者认识不同动物类别之间的生物量差异。

叙事重点不是时间演变或因果推导，而是借助三维体量把分类数据转化为可感知的规模比较。

## 类型辨析与设计启示

- **为什么归入三维信息图形型？** 主要信息由具有深度、厚度和轴测视角的立体方块模块承载，三维空间不是装饰，而是核心的数据表现手段。
- **为什么底层逻辑是编目型？** 数据由多个共享同一主题和计量单位的动物类别组成，条目并列，且字段相对统一。
- **为什么不是编年型？** 不存在时间字段、事件顺序或时间变化趋势。
- **为什么不优先归为混合型信息图形？** 虽然同时使用方块、文字、引导线和动物插画，但这些元素共同服务于同一套三维单位图表达，并非多种独立统计图表的组合。

**可借鉴方法**：将统一计量单位转化为可重复的视觉模块；使用立体分层帮助区分类别；用标签、引导线和具象符号补充语义；同时保留清晰数值与单位图例，避免只凭视觉体量判断精确数据。
