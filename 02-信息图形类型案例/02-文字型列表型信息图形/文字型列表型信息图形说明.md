# 文字型/列表型信息图形（Informational / List Infographics）

## 概念定义
文字型/列表型信息图形以文字条目、编号、短说明和清晰分组为主要信息载体，视觉元素用于提高扫描、识别和记忆效率。它不依赖复杂统计图形，重点是把知识拆分为可快速阅读的单元。

## 1. 主要信息结构
- 标题明确主题与范围。
- 按编号、类别、步骤、清单或优先级组织条目。
- 每条采用相对统一的结构：名称/关键词 + 简短解释 + 可选图标/数据。
- 结尾可加入总结、提示、来源或行动建议。
列表顺序必须有依据：流程顺序、重要程度、类别分组或字母索引，不能让读者猜测。

## 2. 借用的统计图形与计算方式
常见辅助图形包括小型条形图、进度条、比例符号、点图、矩阵和简单流程箭头。若没有可比较的数值，列表本身不应被包装成统计图表。可使用计数、排序、占比或评分，但需说明口径。

## 3. 视觉编码方法
- 点/项目符号：区分条目层级与条目起点。
- 线：分隔条目、连接步骤或形成阅读路线。
- 面：卡片、色块和分组容器区分主题。
- 形/符号：图标帮助快速识别条目，但同一图标需保持同一含义。
- 色彩：强调类别、状态或重点；避免每条随机着色。
- 排版：编号、粗体关键词、短段落和一致间距是主要编码工具。
- 图像：作为识别线索，不应占据空间却不提供信息。

## 4. 信息架构与叙事
推荐顺序：主题说明 → 分类/目录 → 条目列表 → 重点提示 → 总结/来源。单条信息控制在一个主要观点内；内容较长时拆成小标题或分组。通过编号和视觉层级引导读者逐项扫描。

## 6. 更新原则
每个案例补充：列表依据、条目结构是否统一、顺序是否可解释、图标是否有语义、是否含真实统计，以及读者能否快速扫描。后续可将纯文字列表、步骤清单、知识卡片分别建立子标签。
