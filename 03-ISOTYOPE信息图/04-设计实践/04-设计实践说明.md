# 04｜设计实践

## 文件夹用途
本文件夹用于记录将 Isotype 的图符语言、视觉编码与信息组织方法应用于当代信息设计的实践过程。内容包括选题、数据整理、图符设计、编码规范、版式设计、测试反馈与成果归档。

设计实践的目标是借鉴其清晰、系统、易理解的视觉表达方法，而不是机械复制历史作品的造型或版式。

## 设计实践流程

### 01｜确定主题与传播对象
- 选择适合图符表达的主题，如公共知识、社会现象、生活方式、环境、教育或文化。
- 明确目标受众、阅读场景和传播媒介。
- 提炼一个清楚的核心问题，避免主题过宽。

### 02｜收集与整理信息
- 记录数据来源、时间范围、统计单位和采集方式。
- 区分事实数据、背景说明、观点和推断。
- 检查缺失值、重复值、单位不一致和口径差异。
- 对不能核实的数据不作确定性表达。

### 03｜建立信息结构
- 确定采用分类、比较、时间、层级、地理分布或过程等逻辑。
- 整理标题、主要信息、辅助说明、图例和来源。
- 先确定阅读顺序，再选择视觉表现形式。

### 04｜设计图符系统
- 将核心对象转化为易识别、易重复的简化图符。
- 统一图符的视角、比例、线条、细节密度和造型规则。
- 建立图符清单，记录每个符号的名称、含义和使用条件。
- 对容易混淆的图符进行辨识测试。

### 05｜建立视觉编码规范
- 明确图符重复、大小、颜色、位置和连接方式分别代表什么。
- 为数量编码设置明确单位与换算关系。
- 为分类色彩建立图例，并保证色彩在不同媒介中的可辨识性。
- 避免同一视觉变量在同一作品中承担相互冲突的含义。

### 06｜完成版式与信息叙事
- 通过标题、分区、图形、图例和注释建立层级。
- 让阅读路径自然、明确，重点信息突出。
- 控制信息密度，避免图符过小、标签拥挤和装饰干扰。
- 在作品中标注数据来源、时间范围和必要的解释。

### 07｜测试与迭代
- 邀请目标受众完成快速阅读或信息查找任务。
- 观察受众能否正确理解图符含义、数量关系和阅读顺序。
- 记录误读点、查找时间和反馈意见。
- 根据测试结果调整图符、图例、色彩和版式。

## 设计交付清单
| 交付内容 | 主要要求 |
|---|---|
| 主题与受众说明 | 说明设计目标、受众和使用场景 |
| 数据与资料表 | 标注来源、单位、时间范围和口径 |
| 信息架构草图 | 展示信息分类与阅读顺序 |
| 图符设计稿 | 包含单体图符、组合图符和统一规范 |
| 视觉编码规范 | 说明形状、数量、色彩、位置等映射关系 |
| 信息图成品 | 提供清晰的完整画面与必要图例 |
| 测试记录 | 记录受众理解情况与修改过程 |
| 设计总结 | 说明方法借鉴、问题和改进方向 |

## 设计质量检查
- **准确性**：数据是否可追溯，图形是否忠实表达数据。
- **一致性**：图符、色彩、线条和文字规范是否统一。
- **可读性**：受众能否快速识别符号并理解信息。
- **可解释性**：数量单位、图例和编码规则是否明确。
- **可访问性**：避免只依靠颜色传递关键信息，注意文字大小与对比度。
- **适配性**：在屏幕、印刷品和不同尺寸下是否仍然清晰。
- **原创性**：借鉴方法而非直接复制受版权保护的作品。
