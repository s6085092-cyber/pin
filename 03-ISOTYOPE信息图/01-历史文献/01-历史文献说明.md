# 01｜历史文献

## 文件夹用途
本文件夹用于收集、整理与研究 Isotype（International System of Typographic Picture Education，国际文字图像教育系统）相关的历史文献、原始出版物、人物资料、展览资料及学术研究。重点是建立可追溯的史料基础，梳理其产生背景、发展过程与传播脉络。

> 文件夹名称按仓库既定命名保留为“ISOTYOPE”；本说明中的研究对象采用常见拼写“Isotype”。

## 研究内容
1. **历史背景**：20世纪初期的社会教育、公共统计传播、博物馆展示与大众信息设计背景。
2. **发展脉络**：相关组织、项目、出版物、展览及传播实践的时间线。
3. **重要人物与机构**：记录参与者、设计者、研究者、出版机构及相关组织的角色。
4. **原始文献**：书籍、图册、统计图表、海报、展览目录、手稿、档案与影像资料。
5. **学术研究**：论文、专著、评论及对 Isotype 方法的历史评价与当代研究。

## 文献登记规范
每条资料尽量记录以下字段：

| 字段 | 记录要求 |
|---|---|
| 文献名称 | 使用原文标题；必要时补充中文译名 |
| 作者/机构 | 记录作者、编者、设计者或发布机构 |
| 时间 | 出版、创作或发布年份；不确定时标注“约” |
| 文献类型 | 原始出版物、档案、论文、专著、展览资料等 |
| 来源 | 馆藏、出版社、数据库或网页名称 |
| 链接/馆藏号 | 保留可访问链接、DOI、ISBN或档案编号 |
| 内容摘要 | 概括与 Isotype 相关的核心信息 |
| 可信度说明 | 区分一手史料、学术研究与二手介绍 |
| 使用状态 | 待核验、已核验、已引用、授权情况待确认 |

## 整理原则
- 优先保留可核验的一手资料，并注明资料出处。
- 对不同来源中的年代、人物译名或事件描述存在差异时，分别记录来源，不擅自合并为单一结论。
- 引用图片或扫描件时，记录版权、授权和使用限制。
- 对无法确认的作者、年份和出处明确标注“待核验”，不补造信息。
- 中文翻译与原文并列保存，重要术语尽量保留原文。

## 建议归档结构
- 原始出版物
- 学术论文与专著
- 人物与机构资料
- 展览与项目档案
- 历史时间线
- 参考书目与资料索引

## 本文件夹的成果目标
形成一套可追溯的 Isotype 历史资料库，为后续“图符语言与视觉编码”“案例研究”和“设计实践”提供可靠的历史依据。
