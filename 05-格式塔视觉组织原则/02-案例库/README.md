# 02｜案例库

## 用途
收集格式塔视觉组织原则的经典知觉实验、历史图像、平面设计、信息图形、品牌视觉、出版物、网页和界面案例。案例库以可追溯证据为基础，避免只收集“看起来像”的图片。

## 案例分类
1. **经典知觉案例**：有明确出处的心理学实验、视觉错觉和知觉图形。
2. **平面与品牌设计**：标志、海报、编辑设计、导视和图形系统。
3. **信息图形案例**：数据图表、信息组织、图符和视觉叙事。
4. **数字产品与界面**：网页、移动应用、交互状态和动态反馈。
5. **多原则综合案例**：同一作品中同时体现多个组织原则的案例。

## 每个案例的分析模板
- 案例名称、作者/机构、年代、媒介与使用场景。
- 原始来源链接、馆藏/出版信息、版权状态。
- 画面事实描述：实际可见的形状、间距、颜色、边界、运动和布局。
- 涉及的格式塔原则及具体触发线索。
- 信息层级、阅读路径和视觉编码。
- 该原则带来的效果及可能的误读。
- 设计可借鉴之处、适用条件和局限。
- 与规则库对应文档的交叉链接。

## 命名与文件组织
建议每个案例使用独立目录：`编号-案例名称`，目录内包含 `README.md`、原图或合法引用链接、必要的局部截图及分析材料。图片文件名应简洁并与文档引用一致。

## 证据规范
- 优先使用原始出版物、博物馆/档案馆、学术出版商和作者作品集。
- 对经典错觉图形注明出处，不随意将二次重绘说成原始实验材料。
- 设计案例若无法确认设计者或年代，应标记“待核验”。
- 分清“案例中可观察到的视觉事实”与“该设计有意使用某条格式塔原则”的推断。
- 保存图片前确认许可；不确定时优先保存链接和文字分析。

## 更新规则
新增案例后，在对应规则文档中建立反向链接；涉及多项原则时，注明主导原则与辅助原则，不强行只归入一类。
