# 05｜参考文献

## 用途
集中管理格式塔心理学、视觉知觉、视觉组织、图形设计和信息可视化相关的原始文献、学术研究、专著、教材及可信网络资料。

## 核心入口
- [00-Gestalt概念与分类框架.md](00-Gestalt概念与分类框架.md)：专题的概念、历史脉络、术语和12项工作目录说明。

## 文献分类
1. 格式塔心理学原始理论与历史文献。
2. 视觉知觉与知觉组织的实验研究。
3. 现代视觉认知与视觉科学综述。
4. 平面设计、信息设计和信息可视化应用。
5. 教学资料、专业机构资料与可信在线资源。

## 文献登记字段
| 字段 | 内容 |
|---|---|
| 作者 | 作者、编者或机构 |
| 年份 | 出版/发布年份 |
| 标题 | 原文标题及必要的中文译名 |
| 来源 | 期刊、出版社、机构或馆藏 |
| DOI/ISBN/URL | 可追溯标识 |
| 文献类型 | 原始研究、综述、专著、教材、网页 |
| 对应原则 | 涉及的规则编号 |
| 核验状态 | 已核验/待核验 |
| 摘要与用途 | 本专题引用该文献的具体理由 |

## 引用与核验原则
- 尽可能记录完整书目信息及 DOI、ISBN 或稳定 URL。
- 区分原始理论文献与后来的教学性归纳。
- 网络文章可用于理解设计应用，但不自动视为心理学原始证据。
- 不确定的出版信息标注“待核验”，不猜测卷期、页码或 DOI。
- 各规则文档应将引用放在对应论点附近，避免只在文末罗列无关书目。
