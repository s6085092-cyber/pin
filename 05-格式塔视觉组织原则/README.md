# 05｜格式塔视觉组织原则（Gestalt Principles of Visual Organization）

## 专题定位
本专题研究格式塔心理学及其在视觉设计中的组织原则，关注人如何将视觉刺激组织为群组、整体、主体与背景，以及设计师如何利用这些感知倾向组织信息、建立层级并引导阅读。

本专题是**视觉认知与设计方法研究**，不是信息图形表现类型，也不是数据逻辑分类。它与仓库中的信息图形类型、ISOTYPE 图符系统专题并行：
- 信息图形类型：回答信息以何种表现结构呈现。
- ISOTYPE：研究如何建立系统化图符语言。
- 格式塔视觉组织原则：研究视觉元素如何被感知、分组和理解。

## 研究范围与分类说明
本专题采用12项常见的现代视觉设计研究原则作为**工作目录**：接近律、相似律、连续律、闭合律、图底关系、简洁律、共同区域律、共同命运律、对称与秩序、整体涌现、恒常性、多稳态。

**重要学术说明：** Gestalt 心理学没有一份由所有学者共同认可、数量固定的“完整定律清单”。不同教材和设计资料的分类、命名与纳入范围不同。此处12项是便于学习、分析和设计实践的专题目录，不表示它们全部由早期格式塔学派以同等地位提出，也不表示每一项都是严格意义上的经典定律。具体历史归属和术语边界须在参考文献及各规则文档中核验。

## 统一研究框架
每项原则按以下维度研究：
A. 定义与概念；B. 视觉认知解释；C. 视觉组织特征；D. 经典与当代案例；E. 信息图形/界面应用；F. 设计实践；G. 常见误区；H. 参考来源。

## 研究与归档规范
- 区分理论原文、可靠二手解释、案例观察和设计推论。
- 不把设计经验直接说成心理学定律；对证据不足的解释标注“待验证”。
- 案例需记录作者/机构、年代、来源链接、作品语境及版权状态。
- 实验需说明变量、控制条件、观察任务和结果，不以主观印象代替证据。
- 视觉编码需说明实际承担的含义；不得仅凭颜色、大小或位置猜测数据含义。
- 新增或修订原则时，保留术语来源、中文译名差异和分类依据。

## 术语提示
“Law / Principle / Principle of Organization”等命名在不同资料中并不完全一致。仓库文件名采用便于检索的英文常用名称，正文中记录译名差异及其适用语境。
