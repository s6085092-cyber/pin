# Symmetry and Order｜对称与秩序

## A. 定义与概念
对称结构和规则排列常使元素更容易被感知为具有组织关系或形成稳定整体。此处将对称性与秩序性作为设计研究中的相关组织线索合并讨论。

**核心关注：** 对称组织

## B. 视觉认知解释
对称轴、镜像对应、规则间距和重复结构能提供可预测的组织线索。其作用会受到任务、复杂度和其他分组线索影响。

## C. 视觉组织特征
镜像、轴线、平衡、重复网格和规律排列可建立秩序；不对称布局也可以通过视觉重量达到平衡。

## D. 案例研究入口
本规则的案例应归档至[02-案例库](../../02-案例库/README.md)，并在此处补充案例链接。优先收录可追溯的经典知觉实验、出版物或设计作品；记录作者、年代、来源及观察条件。当前尚未绑定具体案例，避免把未经核实的网络配图当作历史实验原图。

建议观察：
- 该规则在案例中由什么视觉变量触发？
- 是否与其他分组线索同时出现？
- 观察者是否能在短时间内正确识别关系？
- 是否存在反例或容易产生歧义的条件？

## E. 信息图形与界面应用
对照式信息图、左右比较、双栏结构、矩阵和系列图表可使用对称或规则网格。

## F. 设计实践步骤
先确定内容之间是否适合对应比较；用对齐和网格建立秩序；必要时用不对称强调重点。

## G. 常见误区与边界
对称不等于公平或数值相等；强行对称会扭曲数据；不要为追求版面对称而隐藏不平衡结果。
