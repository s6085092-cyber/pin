# Invariance｜恒常性

## A. 定义与概念
在大小、位置、方向、视角或部分外观变化时，观察者仍可能识别对象的身份或结构不变量。不同研究领域对 invariance 的使用范围并不完全一致，本专题将其作为视觉识别中的变化容忍问题研究。

**核心关注：** 变化中识别

## B. 视觉认知解释
对象识别可以依赖相对稳定的结构特征，而不完全依赖某一个固定尺寸或方向。具体可识别范围受对象熟悉度、变换幅度和观察条件影响。

## C. 视觉组织特征
轮廓、比例关系、关键特征和结构模式可在缩放、旋转或视角变化中保持识别。

## D. 案例研究入口
本规则的案例应归档至[02-案例库](../../02-案例库/README.md)，并在此处补充案例链接。优先收录可追溯的经典知觉实验、出版物或设计作品；记录作者、年代、来源及观察条件。当前尚未绑定具体案例，避免把未经核实的网络配图当作历史实验原图。

建议观察：
- 该规则在案例中由什么视觉变量触发？
- 是否与其他分组线索同时出现？
- 观察者是否能在短时间内正确识别关系？
- 是否存在反例或容易产生歧义的条件？

## E. 信息图形与界面应用
建立跨尺寸图标系统；让图符在不同版面和设备上保持识别；制定最小尺寸与简化规范。

## F. 设计实践步骤
识别图符的关键特征；测试缩放、旋转、单色和低分辨率状态；记录识别失败的边界。

## G. 常见误区与边界
恒常性不是任何变形下都能识别；不能把它与颜色恒常性、形状恒常性等具体知觉概念不加区分地混用。
