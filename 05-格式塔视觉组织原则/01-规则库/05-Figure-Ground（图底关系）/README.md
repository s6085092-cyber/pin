# Figure-Ground｜图底关系

## A. 定义与概念
视觉场通常会被组织为较突出的主体（figure）与其所依附的背景（ground）。主体与背景的分化帮助观察者确定注意焦点和形状边界。

**核心关注：** 主体背景

## B. 视觉认知解释
主体—背景组织与轮廓归属、面积、对比、封闭性、对称性和注意任务等因素有关；部分图形可能发生可逆的图底切换。

## C. 视觉组织特征
明度、色相、饱和度、边缘清晰度、空间留白和遮挡可强化主体与背景的区分。

- 观察者是否能在短时间内正确识别关系？
- 是否存在反例或容易产生歧义的条件？

## E. 信息图形与界面应用
突出核心数据系列、关键地图区域或主要图形；弱化网格和装饰背景；用留白和对比建立视觉焦点。

## F. 设计实践步骤
确定主信息；降低背景竞争；检查文字与图形对比度；测试主体在不同屏幕和打印环境中的可辨识度。

## G. 常见误区与边界
图底关系不只是“深色前景浅色背景”；背景过强会抢夺注意；双重图形可能有趣但会降低关键信息的即时识别。
