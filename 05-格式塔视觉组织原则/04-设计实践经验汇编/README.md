# 04｜设计实践经验汇编

## 用途
记录格式塔视觉组织原则在真实设计任务中的应用过程、操作方法、迭代记录和经验总结。内容可以来自信息图形、品牌视觉、海报、编辑设计、网页和移动界面。

## 实践内容分类
1. 信息分组与版面层级：接近律、相似律、共同区域律。
2. 阅读路径与流程组织：连续律、共同命运律。
3. 图形简化与符号识别：闭合律、简洁律、恒常性。
4. 主体突出与负空间：图底关系、多稳态。
5. 整体形态与版面秩序：整体涌现、对称与秩序。
6. 多原则综合应用：多个视觉线索共同作用的设计复盘。

## 每次实践记录
- 项目名称、目标、受众、媒介和约束条件。
- 原始问题：当前版面或视觉表达哪里难以理解？
- 使用原则：选择了哪些原则，为什么？
- 设计动作：调整了哪些距离、颜色、边界、连接、形态或运动。
- 前后对比：保留初稿、修改稿和最终稿。
- 验证方式：自查、用户测试、任务完成率或反馈记录。
- 结果与局限：哪些改善有效，哪些问题仍存在？
- 可复用经验：适用条件、禁用条件和注意事项。
- 关联规则、案例和实验文档链接。

## 经验沉淀原则
- 经验必须来自明确的设计操作或测试观察，不将个人偏好写成普遍规律。
- 记录设计前后差异，说明改变了什么以及为什么。
- 当多条原则同时出现时，区分主导原则和辅助原则。
- 不为追求视觉简洁而牺牲数据准确、可访问性和必要说明。
- 重要经验应链接到相应规则文档及案例。

## 输出目标
逐步形成可执行的版式检查清单、图符设计规范、信息分组方法、阅读路径优化方法和设计复盘案例。
