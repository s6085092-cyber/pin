# 04｜统计图形分析

## 专题定位
本目录专门研究统计图形（Statistical Charts / Statistical Graphics）的表达原理、数据映射、图形结构、阅读方式与适用边界。重点回答：**数据如何通过统计图形被编码、比较、解释，以及如何判断一种图表是否适合当前数据与分析问题。**

本目录属于仓库中的统计表达与图表分析专题，不等同于“02-信息图形类型案例”中的信息图形表现类型。统计图形通常承担数据编码和定量比较；信息图形则可能在统计图形基础上进一步加入图符、叙事、说明文字和视觉编码。

## 研究范围
1. **统计图形基础**：数据类型、变量、统计单位、尺度、分布、比较关系及图表编码。
2. **常见图表类型**：柱形图、条形图、折线图、面积图、散点图、直方图、箱线图、饼图、热力图、树图、网络图等。
3. **统计表达方法**：计数、比例、构成、排名、趋势、分布、相关、差异、不确定性和地理空间比较。
4. **视觉编码**：位置、长度、角度、面积、体积、颜色、形状、线型、连接与分面。
5. **图表选择与评价**：数据—任务匹配、准确性、可读性、可访问性、误导风险与信息密度。
6. **信息图形转化**：统计图表如何与图符、插画、文字叙事及版式系统结合。

## 统一分析框架
每个统计图形或案例建议按以下维度记录：
A. **数据基础**：数据来源、观察对象、变量、单位、样本范围、时间范围与数据质量。
B. **分析任务**：比较、趋势、构成、分布、关系、排序、流向或空间定位。
C. **统计方法**：计数、求和、均值、中位数、比例、变化率、分箱、聚合、相关或其他计算；没有计算时明确说明。
D. **图形结构**：坐标轴、标尺、基线、图例、分组、分面、标记和注释。
E. **视觉编码**：位置、长度、角度、面积、颜色、形状、线型、方向和连接分别映射什么数据。
F. **阅读与叙事**：读者从哪里开始，如何比较，重点结论如何呈现。
G. **适用条件与局限**：数据规模、变量类型、精度要求、遮挡、误读和潜在偏差。
H. **设计改进**：如何提升准确性、易读性、可访问性和视觉一致性。

## 图表选择的基本原则
- 先明确分析问题和数据结构，再选择图表；不从视觉样式反推数据。
- 比较数值优先考虑共同尺度上的位置或长度编码；避免无必要的三维效果。
- 时间趋势应明确时间顺序、间隔和单位；折线连接意味着连续或有序关系时才使用。
- 构成图应说明总体、分母和时间点；类别过多时避免难以比较的扇区。
- 分布图应呈现数据离散程度与形态，不只展示单一汇总值。
- 关系图应区分相关与因果；相关性不能单独证明因果关系。
- 面积、角度和体积编码需谨慎，提供标注或辅助刻度。
- 所有图表尽量标注标题、单位、数据来源、时间范围和必要的口径说明。

## 归档规范
- 统计图形原始数据、数据字典和来源信息应一并记录；涉及隐私或授权限制的数据不得公开上传。
- 图表案例优先保留原始来源链接和必要的分析截图，注明作者、年份、出处与许可。
- 说明实际使用的统计计算，不确定时标记“待核验”，不猜测数据处理过程。
- 若案例进一步发展为信息图形叙事，应在02目录对应类型中建立关联，而不是将两个分类维度混为一类。
- 新增图表类型时，说明其数据结构、分析任务、视觉编码、优点、限制及易错用法。
